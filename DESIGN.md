# Visual system
## Scope
Operate: composition comparison. Visual-only redesign. Preserve all existing behavior and factual content. JavaScript and scoring are untouched.
## Direction
Dark, slightly cartoonish workspace explicitly requested by the user. Rounded surfaces, chunkier controls and character portraits. Native Trebuchet/Segoe typography, charcoal ground, amber for the primary action and prediction surface, compact portrait rows. No fabricated statistics or decorative charts.
## Structure
Two side-by-side lineups on desktop; stacked on mobile. Existing native selects, labeled searches, buttons and disclosures. Large contrasting result surface. Evidence remains readable and separate from draft assistance.
## Tokens
Ground #14151c, surface #20222d, raised #2c2f3d, foreground #f0f0e9, secondary #abb0b4, lines #414655, amber #f4ce78. 10px control corners and 20px workspace corners. 44px touch targets and visible keyboard focus. One short result reveal, disabled under reduced motion.
## Design exploration
Grounded directions considered: tournament brackets, collectible roster print, municipal signage, strategy-manual typography, competitive broadcast typography, art-deco cinema, training-ground sportswear. Assigned direction five: competitive broadcast. Darkroom, design-annual and map challengers declined because their layered/ornamental navigation conflicts with the existing native selection flow; borrow their tonal discipline, alignment and legend clarity only. User scope forbids interaction changes.
