# Release status

The composition-only app supports 44 heroes with model `8b35c11d0619`, adding Violet and Nurse Harrow while retaining all previous heroes. The existing research workflow selected a pair-interaction model (regularization 0.001, temperature 1). The scoring implementation is unchanged. Hero search, portraits, lineup sharing, swaps and secondary draft suggestions remain available.

The October 23 refresh used 136,646 matches from the October 20 Nurse Harrow announcement period. Its single-use 20,258-match chronological holdout passed every existing roster-expansion gate: 59.91% accuracy, 0.66336 log loss, 0.23549 Brier and 100% coverage. Both probability losses improve over the incumbent on 2,430 common supported games. See data-refresh-assessment.md for partitions, new-hero cohorts and uncertainty. This is about eight hours of held-out match starts, not established prospective multi-day reliability.

Local TypeScript checks and all 36 tests pass. API smoke checks verified all 44 heroes, both new heroes in a lineup, team-swap symmetry, order invariance, draft suggestions, matching evidence, player-input rejection and private-file rejection. The hosted adapter supports bounded gzip secrets because the selected pair model exceeds the uncompressed environment limit. Compression preserves model values and version. Production deployment verification is pending.

The public beta is hosted at https://deadlock-composition-predictor.vercel.app in julius-projects6. MODEL_JSON and HEROES_JSON are encrypted server-only secrets. Datasets, weights and credentials remain local and ignored. Previous models `5c094e85ad12` and `3debc4970fe5` are archived for rollback; all previous frozen test markers and evaluation data are retained. The old daily reliability automation was deleted after its experiment closed. No prospective monitor for the new model has been started.

Automatic composition detection and live prediction remain deferred. The community watch-tab API does not establish universal discovery or five-second latency. No causal draft quality, exact 58% calibration, production load capacity or future-patch accuracy is claimed. An earlier hosted build emitted a separate node type-definition transpilation warning despite passing repository type checks; monitor that on compiler/platform upgrades.
