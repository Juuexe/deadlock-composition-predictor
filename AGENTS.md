# Project rules

- Use Ponytail full for all coding tasks: smallest complete solution.
- Predict from hero compositions only. Never collect player identities, personal win rates, or player histories.
- Do not display invented probabilities. Train and validate against real match outcomes first.
- Keep draft recommendations secondary. Automatic composition detection and live gameplay predictions are deferred.
- Use short feature branches and pull requests. Run npm run check before committing.
- Keep match datasets, model artifacts, and credentials out of Git.
